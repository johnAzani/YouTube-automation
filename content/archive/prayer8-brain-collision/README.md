# Channel 8 concurrent authoring collision

These files preserve the Gemini Brain output and metadata that raced with the merge
of PR #372. Two queued prayers shared IDs 0600 and 0601 with the owner's approved
launch, and the same run overwrote approved 0602 and three companion Shorts. They
are archived here for reference only; nothing in this directory is scheduled. The
approved versions from merge commit `47a7348d2e21eea5fcaef02ff058586e4bc3bc99`
are restored in the live queue and Shorts directories.

The archived 0600 script has trailing whitespace normalized, so its archived
worksheet checksum refers to the original, unnormalized copy.
