Privacy Policy

Azani Video Studio is a personal video-production workflow maintained by John Azani. It is not offered as a service to the public. This policy explains how the workflow handles information when its owner connects a YouTube account.

Effective date: 21 October 2026

Google and YouTube data accessed

With the account owner's authorization, the workflow requests the Google OAuth scopes youtube.upload and youtube.readonly. It uses them only to:

  • upload the owner's video drafts and their metadata to the owner's YouTube channel;
  • optionally set a thumbnail or add a video to a playlist when configured; and
  • run a weekly performance snapshot for videos whose YouTube privacy status is public.

The metrics workflow excludes private and unlisted videos and does not export channel-level subscriber totals. It stores a snapshot of public-video titles, IDs, publication dates, views, likes, and comments as a GitHub Actions artifact for up to 30 days. It does not commit that metrics file to the repository.

Where information is processed and stored

  • OAuth client credentials and the refresh token are stored as GitHub Actions secrets and are supplied to the relevant workflow at run time. They should not be committed to source control or printed in logs.
  • Rendering and API calls run on GitHub-hosted Actions runners. GitHub processes workflow logs and artifacts under its own policies and the repository's configured retention settings.
  • This source repository and its GitHub Pages site are public. Workflow logs are publicly visible, and workflow artifacts are available to people who can read the repository. Production render artifacts are configured for one-day retention; the public-video metrics artifact is configured for 30-day retention. Do not place passwords, OAuth tokens, or other secrets in scripts, workflow inputs, video metadata, or committed files.
  • Published videos and their public metadata are hosted by YouTube under the channel owner's YouTube settings.

Other providers

When a render needs visual assets, the workflow may send scene-search phrases to stock or open-media providers such as Pexels, Pixabay, Openverse, Wikimedia Commons, the Internet Archive, or NASA. Those queries are for finding media; the workflow does not send the owner's Google OAuth token to those providers. When Microsoft Edge text-to-speech is available, narration text is sent to Microsoft's speech service to generate audio. The workflow does not operate an advertising tracker or analytics cookie on this website.

Sharing

Google/YouTube data is used for the functions listed above and is not sold. It is processed by Google/YouTube and GitHub to provide those functions. Public-video metrics are placed in the public repository's short-lived workflow artifact as described above. Rendered video artifacts may also be accessible to repository readers while they are retained.

Retention and revocation

The owner can delete or replace GitHub Actions secrets at any time. Metrics artifacts expire after 30 days; production render artifacts expire after one day. GitHub retains workflow logs according to the repository's settings. The owner can revoke the app's YouTube authorization from the Google Account security page. Revocation stops future API access but does not automatically delete artifacts or files already stored in GitHub.

Security and contact

Access is limited by Google OAuth authorization and GitHub repository/workflow permissions. No system can guarantee absolute security; the repository owner should use a unique account password, two-step verification, least-privilege access, and GitHub secrets rather than committed credentials. For privacy questions, contact the developer support email shown on the Google OAuth consent screen.
