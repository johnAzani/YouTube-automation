The Secret Place Video Studio

The Secret Place Video Studio is an editorial production workflow for creating devotional prayer and inspirational documentary drafts for The Secret Place channel. It runs rendering and scheduled jobs in GitHub Actions; it is not a public video-hosting service and is not offered to other creators.

What it does

  • Builds a video draft from a script that has been reviewed and approved by its owner.
  • Uses the YouTube Data API to upload the owner's finished draft, with private visibility as the default.
  • When the weekly metrics workflow is run, reads data for the owner's public videos and prepares a short-lived report.

A human remains responsible for checking facts, source licences, originality, video quality, and the privacy setting before any video is made public. The default workflow does not automatically make uploads public.

The source code and workflow documentation are available in the GitHub repository. See the Privacy Policy for the data the workflow handles and the Terms of Use.
